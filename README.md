# ML_BOT
Private Discord bot for Memes_land server

Versionning commit message syntax:
[msg] - v*x*.*x*.*x* (REV-*x*)



Liste des listeners :
- GuildMemberAdd
- GuildMemberRemove
- GuildMemberUpdate
- InteractionCreate
- MessageDelete
- MessageUpdate
- VoiceStateUpdate



Liste des commandes :
- Admin
    - clearCommandeCache (reset le cache commandes du bot)
    - setMaintenanceState (change le mode de maintenance du bot)

- Games
    - phasmoImposteur (lance le mode de jeu phasmo imposteur)
